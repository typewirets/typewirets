Why F12 needed the maintainer

Run on main at 0337a79: an A ⇄ B cycle, with a monitor that returns fallbackA whenever it sees a CircularDependency.

get(A) -> realA | cached B.a -> fallbackA | A again -> realA
  • No request sees an error: the cycle is silently swallowed.
  • The cached B holds the fallback A, but A itself is cached as the real A. The container now holds two different As.

Decided 2026-11-09: a monitor can turn any other error into a value, but can turn a CircularDependency only into another error. That keeps "change behaviour" (reporting, custom errors, fallbacks for ordinary failures) without letting a cycle leave the container inconsistent.
